# Doc QA Bot

A lightweight RAG (Retrieval-Augmented Generation) system that answers
questions about an uploaded PDF, using local embeddings + ChromaDB for
retrieval and an LLM for answer generation.

## Status: 🚧 In progress — learning project

## Setup
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
